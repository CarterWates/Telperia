# TRI v0.1

## Status

Deferred metric. The authoritative TRI v0.1 methodology text, formulas, evidence requirements, and scoring rules must be supplied or explicitly approved before implementation.

## Purpose

TRI is reserved for Telperia reliability methodology. The MVP website may explain the concept, but current result packages must not include numeric TRI scores.

TRI is expected to measure reliability behavior across repeated or operational use, such as:

- Run-to-run stability.
- Error rate.
- Completion consistency.
- Latency consistency.
- Output format adherence.
- Recovery from runtime failures.

## Implementation Rule

Do not implement TRI calculations from this scaffold alone. Use `methodology/deferred-metrics.md` for approved MVP presentation language.
